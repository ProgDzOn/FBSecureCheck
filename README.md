# خادم الدفع لـ SecureBook (Chargily Pay — CIB / الذهبية)

يجب رفع هذا المجلد على **استضافة PHP خاصة بك** (مع cURL)، وليس على GitHub Pages،
لأن المفتاح السري لا يجوز أن يظهر في موقع عام.

## الخطوات
1. أنشئ حساباً في Chargily Pay، وأكمل متطلبات التاجر عندهم، وانسخ **المفتاح السري** (يبدأ بـ test_sk في وضع التجربة).
2. عدّل `config.php`: ضع المفتاح، وأبقِ `CHARGILY_MODE = 'test'` أولاً.
3. ارفع مجلد `securebook-pay` إلى استضافتك (مثلاً `https://yourdomain.com/securebook-pay/`).
4. في `index.html` (موقع SecureBook) عدّل السطر `const PAY_API='';` إلى
   `const PAY_API='https://yourdomain.com/securebook-pay';` (بدون / في النهاية).
5. جرّب الدفع بوضع التجربة، ثم بدّل `CHARGILY_MODE` إلى `live` ومفتاح الإنتاج.

## كيف يعمل
- `create.php` ينشئ عملية دفع بقيمة `AMOUNT_DZD` (يحددها الخادم فقط) ويعيد رابط الدفع.
- بعد الدفع تتحقق `status.php` من البوابة مباشرة، فلا حاجة إلى webhook.
- سجلات التفعيل في `data/payments.json` (محمية بـ .htaccess؛ الأفضل نقل `DATA_DIR` خارج مجلد الموقع إن أمكن).

## تحقق قبل الإطلاق
- عناوين الـ API وحقول الطلب في وثائق Chargily: https://dev.chargily.com
- الحد الأدنى للمبلغ ورسوم البوابة: قد يكون 10 دج أقل من الحد الأدنى أو لا يغطي الرسوم.
- متطلبات التاجر والتسجيل التجاري في الجزائر لقبول الدفع الإلكتروني.
