# 🛡️ SecureBook — Account Security Dashboard

**SecureBook** is a modern, lightweight, and responsive web application designed to help users organize, monitor, and document their Facebook account security reviews through a clean and intuitive dashboard.

Built with modern web technologies, SecureBook provides a centralized interface for reviewing login activity, recording recognized devices, identifying unfamiliar sessions, and maintaining a personal security audit history.

## ✨ Key Features

- **Security Dashboard:** A centralized overview of account security reviews.
- **Official Facebook Access:** Direct links to Facebook's official login activity and security settings.
- **Device Management:** Manually register and manage devices associated with account reviews.
- **Security Classification:** Categorize devices as Trusted, Needs Review, or Unknown.
- **Activity Tracking:** Record device names, locations, and last activity dates.
- **Local Data Storage:** Save review records using browser LocalStorage.
- **Privacy First:** No Facebook passwords, authentication codes, or private account credentials are collected.
- **Responsive UI:** Optimized for desktop, tablet, and mobile devices.
- **Arabic RTL Support:** User-friendly right-to-left interface.

## 🚀 Getting Started

1. Clone this repository:
   `git clone YOUR_REPOSITORY_URL`
2. Open the project folder.
3. Launch `index.html` in your preferred browser.
4. Start managing your security review records.

## 🔐 Privacy & Security

SecureBook operates independently in the browser. It does not directly access Facebook's private authentication sessions or retrieve connected devices automatically.

All device information is manually entered by the user and stored locally in the browser.
